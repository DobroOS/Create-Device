🎮 Что это?
Create Device — это браузерный симулятор-тайкун, в котором вы становитесь основателем технологической компании. Разрабатывайте смартфоны, создавайте операционные системы, нанимайте сотрудников, улучшайте офис и соревнуйтесь с мировыми гигантами — от Pineapple до Gogle.
Всё в одном HTML-файле. Никаких зависимостей, сборок, серверов. Просто откройте в браузере — и играйте.

🚀 Как запустить
Способ 1: Просто скачать

Скачайте index.html из репозитория
Откройте файл двойным кликом в любом современном браузере
Играйте!
